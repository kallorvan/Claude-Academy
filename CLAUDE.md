# Claude-Academy

Repositório de estudo sobre Claude Code e a API da Anthropic. Hoje o projeto contém a documentação de estudo (`PLANO_DE_ESTUDO.md`) e as anotações pessoais; não há código de aplicação ainda.

## Idioma

- Responder e escrever documentação em português do Brasil.
- Nomes de código, comandos, variáveis e mensagens de commit podem ficar em inglês.

## Estrutura

- `CLAUDE.md`: este arquivo, memória persistente do projeto.
- `PLANO_DE_ESTUDO.md`: roteiro do básico ao avançado, com links para a Claude Academy.
- Novos exemplos e experimentos vão em pastas próprias, nomeadas por tema (ex.: `exemplos/hooks/`), nunca na raiz.

## Comandos

Ainda não há build nem testes. Quando existirem, documentar aqui, por exemplo:

- Instalar dependências: _a definir_
- Rodar testes: _a definir_
- Lint/formatação: _a definir_

## Convenções

- Arquivos Markdown com títulos em sentença (“Primeiros passos”, não “Primeiros Passos”).
- Cada exemplo de código deve indicar em qual versão do Claude Code ou da API foi testado, quando for relevante, porque a ferramenta muda com frequência.
- Não colar trechos longos de cursos da Academy; resumir com as próprias palavras e linkar a fonte.
- Ao citar uma lição, usar sempre a URL dela.

## Regras para o Claude

- Antes de criar um arquivo novo, verificar se já existe um equivalente.
- Não alterar `PLANO_DE_ESTUDO.md` sem pedido explícito; ele é a referência do estudo.
- Não commitar segredos (chaves de API, tokens). Usar variáveis de ambiente.
- Commits pequenos, com mensagem descrevendo o porquê da mudança.
